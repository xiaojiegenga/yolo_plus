## 评估口径

- Val 117 图、557 实例；未使用 Test。日期 2026-09-13。
- 本次 000 与 F 均在 CPU、FP32、2 个计算线程上重新推理；Python 3.10.19、PyTorch 2.10.0+cu130、Ultralytics 8.4.80、pycocotools 2.0.11。
- 源码来自 F 分支提交 `1590ccd`，同时加载标准 000 与 F checkpoint。
- 固定 imgsz=640、rect=false、batch=1、conf=0.001、iou=0.7、max_det=300、retina_masks=true。
- GT 多边形由 COCO API 在原图栅格化，预测掩膜映射到原图；COCOeval 101 点插值，IoU=0.50:0.05:0.95。
- 小目标按 bbox 面积乘 `(640/max(H,W))²` <1024 px²；GT 和未匹配预测使用同一大小规则，其他大小 GT 保留为忽略匹配对象。
- 固定工作点为 conf≥0.25、IoU=0.50。
- 使用现有 `scripts/evaluate_c_small_val.py` 的评估逻辑，运行时仅将推理 device 从 0 改为 cpu，并将设备记录标为 CPU。仓库源码未修改。参数为 `--source-root .cache/f-p3strip-branch/ultralytics-main --data-root E:/Study/DeepCNN/yolo26/code/datasets --candidate-run data-v2-abl-f-p3strip-b16-s42 --candidate-label F --output experiment_records/evaluations/data-v2-f-small-val.json`。

## 解释与限制

正式训练的 Mask mAP50-95 从 0.36348 降到 0.35882；本次原图协议从 0.34069 升到 0.34665。收益方向依赖评价协议，F 不能简单归为所有场景都无效。

源码中，正式验证默认在输入的 stride-4 网格计算掩膜匹配；本次使用原图 COCO 栅格化及 retina_masks 原图预测。除此以外，两者在预处理、匹配与 AP 积分、设备和数值精度等方面也有差异。当前没有逐因素控制实验，不能把方向变化唯一归因于掩膜分辨率。

本次 CPU 000 小目标 AP50-95=0.19247，与旧 GPU 000 的 0.19311 略有不同。因此只将本次 CPU 000 与本次 CPU F 相减，旧 000/C/D1 专项结果原样保留，不直接混算。未以本次结果重新选择 epoch。

只有单 seed，尚未建立统计显著性。建议保留 F 为存在局部收益但正式主指标未通过的候选；若继续研究，先在相同预测条件下分离网格与评价协议影响，再决定结构调整或组合。
