原图主指标提高约 0.61 个百分点，方向与正式 Val 的 +0.98 个百分点一致，
但未表现出因使用完整高分辨率原型而产生的大幅增益。原图 Mask AP50 略降，
因此不能把 D1 描述为所有 IoU 阈值均改善。

纯背景图误检增加 3 个，而全部卷叶螟 Mask FP 增加 65 个。
这两个计数覆盖范围不同，但可确认新增误检并不只发生在纯背景图。
含虫图中的重复预测、定位或掩码匹配失败尚未逐例区分，下一步应先查看这部分错误。

## 评估口径与复现

- Val 117 图、557 实例：卷叶螟 462、钻心虫 95；小卷叶螟 174、非小卷叶螟 288。
- 本机 RTX 4060 Ti、Python 3.10.19、PyTorch 2.10.0+cu130、Ultralytics 8.4.80、pycocotools 2.0.11。
  源码为 D 分支训练提交 `7d277b6`，可同时读取标准 000 与 D1 checkpoint。
- 预测统一 imgsz=640、rect=false、batch=1、FP32、conf=0.001、iou=0.7、max_det=300、retina_masks=true。
- GT 由 COCO API 对原图多边形栅格化，预测掩码映射回原图；IoU 在原图计算。
  AP 采用 COCOeval 的 101 点 Recall 插值，IoU=0.50:0.05:0.95。
- 大小分组按 bbox 面积乘 `(640/max(H,W))²`；小目标阈值为 <1024 px²。
  GT 与未匹配预测使用同一 bbox 分组规则，保留其他尺寸 GT 为忽略匹配对象。
- 固定工作点 P/R 使用 conf≥0.25、IoU=0.50，不使用训练日志的最大 F1 工作点。
  组内 FP 不是纯背景图 FP；两者分别记录。
- 本次重算 000 的全部 Box/Mask 类别及尺寸指标与已有 C 专项中的 000 完全一致。
  原 C 专项数据保持原样。

在本地项目根目录运行：


`--source-root` 指向 D 独立 checkout 的 `ultralytics-main`。脚本保留 C 默认参数，D1 显式指定候选和输出。

## 结论范围与来源

只有一个训练 seed；两个固定权重不再挑 epoch。补充评估与训练 Val 的预处理、GT 栅格化、
掩码输出网格及 AP 积分协议不同，不能跨协议直接相减，也不能把两者的差唯一归因于输出分辨率。
本地数据规模及类别、尺寸计数与主计划一致；密集场景未单独分组。Test 未使用。
