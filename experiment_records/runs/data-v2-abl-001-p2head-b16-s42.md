## 结构与预训练迁移

权重模型的末层是 `Segment26P2Lite`，输入层号 `[27,16,19,22]`，stride 为 4/8/16/32；
没有 CBAM 参数或实例 Dice 配置。用实际 best.pt 做 640 合成输入前向，预测形状为
`[1,300,38]`，Proto 为 `[1,32,160,160]`，输出均有限。标准 P3-based Proto 保留。

日志中的迁移过程为：官方 80 类模型先迁移 904/1078 项；训练器重建为 2 类 C 模型时迁移
1060/1078 项，18 个类别相关张量因形状改变不迁移。它与独立检查中“官方权重直接迁移到
2 类 C 模型”的 890/1078 口径不同；训练器重建同时保留已初始化的 P2 张量。

## 结论范围与后续

本次 C 在正式主指标、两类 Recall/AP 和成本上的权衡不足以通过门控，不进入 A+C、B+C 或
A+B+C。A1/B 同样未通过门控，A2 近似持平；保留这些独立结果，不把尚未验证的组合命名为有效 Ours。
如果提出新的结构或初始化假设，应使用新 Run ID 进行独立验证；当前不自动开始下一轮训练。

全部正式训练只有 seed=42，没有多 seed 统计显著性结论。专项评估在本机执行，掩膜生成和
指标积分规则与训练日志不同，适合在其自身协议内比较 000/C；密集场景没有另行分组量化。
本机数据规模与主计划吻合，但云端日志未附逐图数据版本证明。Test 本次完全未使用。
