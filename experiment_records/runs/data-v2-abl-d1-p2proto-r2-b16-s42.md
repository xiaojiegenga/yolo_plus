# Run 记录：data-v2-abl-d1-p2proto-r2-b16-s42

## 结论

**D1 是当前已完成单模块实验中主指标最高的候选，建议保留并继续围绕掩码分支讨论改进。**
300 epoch 已完成，official fitness 最佳轮次为 278；Mask mAP50 / mAP50-95 为
0.71245 / 0.37327，相对正式 000 增加 0.00113 / 0.00979，即 0.113 / 0.979 个百分点。
训练结束的分类别日志显示，卷叶螟 Mask mAP50-95 从 0.266 提高到 0.290，钻心虫从 0.461 略降到 0.458。
中后段平均主指标也高于 000，正向结果不只体现在最佳单轮。当前保留为候选，最终方案尚未冻结。

## 结构与指标口径

D1 保留检测 stride=8/16/32，只在原型分支增加 P2 注入、窄通道上采样与细化。
640 输入时原型从 32×160×160 变为 32×320×320，与 mask_ratio=2 的训练监督尺寸一致。
最终权重末层为 `Segment26P2`，包含 918 个状态张量。

正式训练默认 Val 沿用 000 的 stride-4 网格：D1 的高分辨率原型先双线性降采样至输入尺寸的 1/4，
再组合与裁剪掩码；GT 使用相同评估尺寸。正式指标因此具有一致的评估网格，但不能完整描述原图掩码表现。
固定 best.pt 的补充评估采用 `retina_masks=true`，在原图计算 Mask IoU，详见独立评估记录。

总体指标统一取 official fitness = Box mAP50-95 + Mask mAP50-95 最大行的 CSV 精确值。
类别指标来自训练结束的 best.pt 验证日志，只有三位小数；不把它们与 CSV 拼接重算总体指标。

## 下一步讨论依据

保留 D1 作为当前优先候选，A1/B/C 的负结果与 A2 的近似持平结论继续保留。
下一步优先查看含虫图中的卷叶螟新增误检，区分重复预测、定位偏差、类别错误和掩码重叠不足，
再选择一个针对性假设。若继续改原型分支，可讨论保留原有粗原型输出、让 P2 分支只提供残差细化，
以减少新增路径对已有表征的扰动；这是待验证设计，当前误检增加的根因尚未确定。
新设计须使用新 Run ID，并与 000 和 D1 同时比较。当前不调整冻结训练配方、不直接叠加 A/B/C，
也不把 D1 命名为已冻结 Ours。

## 已知问题与结论范围

- 部分 Val loss 出现 NaN：box/dfl 在 epoch 3、4、186；seg/cls 在 epoch 3、4、76、186。
  全部训练损失、P/R/mAP、最佳轮次损失以及最终两份权重张量有限；300 epoch 正常完成。
  000 也有部分 Val loss NaN，但这不能证明两者原因相同。当前没有定位 NaN 根因，不能把本轮写成全程数值无异常。
- Val semantic loss 全为 0，是该验证路径不返回语义辅助预测的记录值，不表示语义误差为零。
- 仅 seed=42，尚无跨 seed 稳定性结论；主指标提升约 0.01，适合保留候选，不能宣称统计显著。
- D1 同时改变 P2 信息注入、原型分辨率、细化宽度与部分参数初始化；当前实验不能分离各自贡献。
- 默认正式 Val 和原图 COCO 补充评估属于不同协议，各自在同协议的 000/D1 内比较。Test 未使用。
