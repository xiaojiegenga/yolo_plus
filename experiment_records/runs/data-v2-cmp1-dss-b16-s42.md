### 消融分析

1. **贡献排序与占比**：双分辨率 +4.10 pp（159%）> DSEM +3.13 pp（121%）> P2 注入 +1.13 pp
   （43.8%）> SFCM 门 +0.79 pp（30.8%），全部超过 ±0.005 噪声地板，**无死组件，最终模型维持
   本 Run 完整复合不变**。
2. **强协同**：留一贡献合计 9.15 pp ≫ 净收益 2.58 pp，各组件边际贡献大量重叠；移除任一大
   组件（双分辨率或 DSEM）复合即跌破基线，移除两个小组件（门/注入）仍保持正收益
   （+1.79 / +1.45 pp）。机制解释：P2 注入的细节必须经 stride-2 残差级才能变现（nodual 中
   p2_proj 学习范数从 7.36 萎缩至 5.04），DSEM 的增强同时经主干传播与跨阶段注入两路生效。
3. **分类型画像互补**：门的收益集中在卷叶螟（去门 0.306→0.277）、双分辨率去掉后卷叶螟崩至
   0.244（跌破基线 0.266）且 Mask 召回 0.653→0.551、P2 注入的损失也偏卷叶螟（−1.6 pp）；
   DSEM 的相对损失更偏钻心虫（0.477→0.438，−3.9 pp）。三机制覆盖两类目标，是复合设计的
   直接证据。
4. **置信度-误检权衡**（原图 COCO 配对口径）：conf≥0.5 低 IoU 高置信率呈完整梯度——
   nodual 12.9% < nosfcm 15.1% < 000 17.0% < nop2inj 18.5% < cmp1 20.6% < nodsem 22.9%。
   双分辨率、门、注入都在抬高预测置信度（换来主指标收益），DSEM 轻度压制误检；SFCM 的
   "背景抑制"原设计假设被证伪——门是置信度放大器，论文机制叙事按此表述。
5. **跨协议一致性**：四个消融在原图 COCO 口径的排序与训练网格口径一致（总体：
   nodual 0.34111 ≈ nodsem 0.34156 < nop2inj 0.34810 < nosfcm 0.34965 < cmp1 0.36166）；
   双分辨率与注入的收益在两口径下均集中在卷叶螟。
6. **成本**：nodual 128.3 GFLOPs（hi 级约 11.5 G）、nodsem 137.9 G / 23.83 M（无 DSEM 3.7 万
   参数）、nop2inj 136.4 G（p2_proj 约 3.4 G）、nosfcm 139.8 G（结构与本 Run 完全对齐）。

  （此前最好为 D1 的 +0.98 pp），通过全部预注册性能门控（主门 0.36848 / 机制目标 0.37327 /
  理想线 0.37827 均越过）。四组件激活范数：α 1.303（256/256 通道）、γ 2.309、p2_proj 7.364、
