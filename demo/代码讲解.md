# 水稻害虫实例分割检测系统 V1.0 —— Demo 代码讲解

> 写给有一点 Python 和 HTML5 基础、但没做过 Web 应用的读者。
> 建议按顺序读：第 1–2 章建立全景认知，第 3 章补齐前置概念，
> 然后对照源码细读第 4–6 章。读完你应该能独立改出自己想要的版本。

## 1. 这个 Demo 是什么

一句话：**把训练好的 DSS 实例分割模型包装成一个"网页软件"**。

你以前的用法是在命令行里跑脚本（训练、评估），而 Demo 是一个有界面的软件：
浏览器里打开一个页面，上传（或拖入）一张稻田照片，页面把图片发给后端，
后端调用模型推理，把画好分割掩码和边界框的结果图连同统计数据返回，
页面渲染出来。整个过程约 0.1–2 秒（GPU / CPU）。

它由两部分组成，这就是所谓**前后端分离**架构：

```text
┌─────────────────────────── 你的电脑 ───────────────────────────┐
│                                                                 │
│   浏览器（前端）                Python 程序（后端）              │
│   demo/static/                  demo/app.py                     │
│   ┌───────────────┐    HTTP     ┌────────────────────┐          │
│   │ index.html    │ ──────────> │ FastAPI 服务        │          │
│   │ style.css     │  上传图片    │   │                │          │
│   │ app.js        │ <────────── │   └─> DSS 模型     │          │
│   └───────────────┘  JSON 结果  │       (best.pt)    │          │
│                            │     └────────────────────┘          │
└────────────────────────────┼─────────────────────────────────────┘
                             │ 也负责把网页文件发给浏览器
                    http://127.0.0.1:8000
```

- **前端**：运行在浏览器里的"页面 + 逻辑"，本 Demo 用最朴素的三件套
  HTML（结构）/ CSS（样式）/ JavaScript（行为），不依赖任何第三方框架，
  离线也能跑。
- **后端**：一个常驻内存的 Python 程序（`app.py`），启动时把模型加载进
  显存/内存，然后一直监听 8000 端口等待请求。前端不直接接触模型和权重。

**为什么要分成两部分？** 因为浏览器（沙箱环境）既拿不到你硬盘上的权重文件，
也不适合运行 PyTorch；而 Python 后端不擅长画界面。两者用 HTTP 协议通信，
各干各擅长的事。

## 2. 一次检测的完整旅程

理解了这个流程，后面的代码就只是"往骨架上填肉"：

1. 浏览器打开 `http://127.0.0.1:8000`，后端把 `index.html` 发回去；
2. 页面加载时，`app.js` 自动请求 `/api/info` 和 `/api/samples`，
   在页头显示设备/权重/类别标签，渲染示例图片按钮；
3. 你上传/拖入/粘贴一张图（或点示例图），前端本地生成预览；
4. 点击「开始检测」，前端把图片文件和置信度阈值打包成 **FormData**，
   `POST` 到 `/api/predict`；
5. 后端收到请求：校验格式和大小 → 解码为像素数组 → 调用
   `MODEL.predict(...)` 推理；
6. 模型输出：每个害虫实例的掩码、边界框、类别、置信度；
7. 后端用 `result.plot()` 把这些画在原图上得到标注图，
   转成 JPEG 再 **base64 编码**成字符串；
8. 后端把 `{标注图, 实例列表, 耗时, ...}` 打包成 **JSON** 返回；
9. 前端解析 JSON：标注图塞进 `<img>` 的 `src`，统计卡片、明细表、
   历史记录逐个渲染；
10. 页面更新完毕，你看到结果。全程无刷新（这叫 **AJAX / 异步请求**）。

## 3. 前置概念速补（5 分钟）

没接触过 Web 开发的话，这几个词先混个脸熟，后面遇到再回来查：

| 概念 | 一句话解释 |
|---|---|
| **HTTP** | 浏览器和服务器之间"说话的规矩"。一次通信 = 一个请求（request）+ 一个响应（response） |
| **GET / POST** | 两种最常用的请求方法。GET 用于"取数据"（如获取页面）；POST 用于"提交数据"（如上传图片） |
| **URL / 路由** | `http://127.0.0.1:8000/api/predict` 里，`/api/predict` 就是路由。后端给每个路由绑定一个处理函数 |
| **JSON** | 一种文本格式的数据结构，长得很像 Python 的字典/列表，是 HTTP 传输结构化数据的通用语。`{"instance_count": 2}` |
| **base64** | 把二进制数据（图片字节）编码成纯文本的方案，这样图片就能塞进 JSON 里传输。代价是体积膨胀约 33% |
| **FormData / multipart** | 浏览器上传文件的标准格式：一个"多部分"的表单，可以同时装文件和普通字段 |
| **API** | 应用编程接口。这里指后端暴露给前端调用的那几个 URL（`/api/info` 等） |
| **异步 / await** | 发出请求后不等结果先干别的，结果回来再处理。JS 用 `async/await`，Python 用 `async/await`，写法几乎一样 |
| **端口 127.0.0.1:8000** | `127.0.0.1` 是"本机自己"，8000 是程序的"门牌号"。换端口 = 换门牌 |
| **DOM** | 浏览器把 HTML 解析成一棵可编程修改的树，JavaScript 通过 `document.getElementById(...)` 拿到树上某个节点来改内容/样式 |

## 5. 后端 `app.py` 逐段精讲

后端代码按功能分为六个区块，下面按出现顺序讲。建议对照源码读。

### 5.1 模块文档字符串与环境准备（文件开头到 `from ultralytics import YOLO`）

Python 的三引号字符串放在文件最顶部就是**模块文档**，`help()` 能看到。
软著材料里它就是"软件功能说明"的第一手来源。

接下来是最容易踩坑的一段，核心是三件事必须在 `import ultralytics` **之前**做完：

1. **算路径**。`Path(__file__).resolve().parents[1]` 的意思是：
   `__file__` 是当前文件 `app.py` 的路径，`parents[1]` 是它的上一级目录
   （即项目根目录 `yolo_plus`）。为什么不写死 `E:\Study\...`？
   因为换电脑、传到云服务器后路径就变了，动态计算才能到处能跑。

2. **设环境变量** `YOLO_CONFIG_DIR`，让 ultralytics 把配置写到项目内的
   `.cache` 目录，而不是你的用户主目录——和仓库其他脚本的约定保持一致。

3. **把 `ultralytics-main` 插入 `sys.path`**。这是全项目最关键的一行：
   你的模型用了自定义网络结构（`Segment26DSS` 等），这些类只存在于仓库
   内置的 `ultralytics-main` 里。Python 加载 `best.pt` 时需要"认得"这些类，
   所以必须让解释器优先搜索这个目录。你的训练/评估脚本用的同一招。

中间还有一小段处理 Windows 控制台编码（GBK → UTF-8），防止打印中文报错。

注意这些 `import` 语句都排在环境准备**之后**，所以加了
`# noqa: E402` 注释——这是告诉代码检查工具"我知道 import 没放最上面，
故意的"。（E402 = "import 不在文件顶部"这个检查编号。）

### 5.2 常量配置

```python
DEFAULT_WEIGHTS = REPO_ROOT / "runs" / "data-v2-cmp1-dss-b16-s42" / "weights" / "best.pt"
INPUT_SIZE = 640
CLASS_META = {
    "Rice leaffolder": {"name_zh": "稻纵卷叶螟", "color": "#f59e0b"},
    "Rice stemborers": {"name_zh": "稻螟虫", "color": "#06b6d4"},
}
```

把"可能会改的东西"集中放顶部是良好习惯：换权重只改一行，换类别色只改一处。
`CLASS_META` 的 key 必须和训练数据集的类别英文名**一字不差**，
查一下 `MODEL.names` 就能对上；遇到对不上的类别会回退成原名加紫色，
程序不会崩——这叫防御式编程。

### 5.3 应用实例与 `init_model()`

```python
app = FastAPI(title=...)
MODEL: YOLO | None = None
```

`app` 是 FastAPI 应用对象，下面所有 `@app.get(...)` 装饰器都是往它身上
注册路由。模型本体存在模块级全局变量 `MODEL` 里——单进程、单模型的演示
系统这样写最直白（多模型/多进程才需要更复杂的容器）。

`init_model()` 做三件事：

1. 检查权重文件存在，不存在就给出带修复提示的报错（比裸抛异常友好）；
2. 自动选设备：`torch.cuda.is_available()` 为真用 `cuda:0`，否则 `cpu`。
   你本机是 RTX 4060 Ti，会自动走 GPU；
3. **预热**：正式服务前先用一张全黑图跑一次推理。因为第一次推理包含
   显存分配、算子编译等一次性开销（可能几秒），预热后用户第一次真实
   检测的耗时就稳定在正常水平。这是推理服务的常见工程手段。

### 5.4 静态资源与根路由

```python
@app.get("/")
def index():
    return FileResponse(STATIC_DIR / "index.html")

app.mount("/static", StaticFiles(directory=STATIC_DIR), name="static")
```

- 访问 `/` 返回主页 HTML；
- `app.mount("/static", ...)` 把整个 `static/` 目录挂到 `/static/` 路径下，
  于是浏览器请求 `/static/style.css` 就能拿到样式表，`/static/app.js`
  拿到脚本。**同一个服务既当 API 又当网站服务器**，演示系统这样最省事
  （正式产品通常前后端分开部署）。

### 5.5 五个接口

#### `GET /api/info` —— 模型名片

把 `MODEL.names`（形如 `{0: "Rice leaffolder", 1: "Rice stemborers"` 的
字典）转成列表，补上中文名和颜色；再附上设备名、参数量（
`sum(p.numel() for p in model.parameters())`，2386 万）、输入尺寸等。
前端页头那排绿色小标签就是它提供的。参数量除以 `1e6` 得到"23.9M"。

#### `GET /api/samples` 与 `GET /api/samples/{name}` —— 示例图

前一个用 `Path.glob("*.jpg")` 列出 `samples/` 目录所有图片，
`sample_label()` 根据文件名里是否含 `leaffolder`/`stemborer` 生成中文标签。

后一个值得学的是**安全校验**：

```python
path = (SAMPLES_DIR / name).resolve()
if path.parent != SAMPLES_DIR.resolve() or not path.is_file():
    raise HTTPException(status_code=404, detail="示例图片不存在")
```

如果直接拿用户传的 `name` 拼路径读文件，攻击者可以传
`../../app.py` 之类读到服务器任意文件（叫**路径穿越攻击**）。
`resolve()` 把路径规范化后检查父目录确实是 `samples/`，就堵死了。
写任何"根据用户输入读文件"的接口都要做这一步。

#### `POST /api/predict` —— 核心（重点看）

函数签名：

```python
async def predict(file: UploadFile = File(...), conf: float = Form(0.25)) -> dict:
```

FastAPI 的优雅之处：**参数类型即文档、即校验**。声明 `file: UploadFile`，
它就自动解析 multipart 里的文件；声明 `conf: float = Form(0.25)`，
它就把同名表单字段转成浮点数，前端没传就用默认值 0.25。字段名
`file`、`conf` 与前端 `formData.append("file", ...)` 一一对应——
**前后端就是靠这两个名字对上的**，改一处必须改另一处。

函数体分五步（源码里有编号注释）：

1. **校验**：后缀白名单、非空、20MB 上限。不合法就抛 `HTTPException(400, 中文提示)`，
   前端能把提示原样弹给你看；
2. **解码**：`await file.read()` 拿到原始字节 → `Image.open(io.BytesIO(data))`
   像打开文件一样从内存里解析图片 → `.convert("RGB")` 统一通道 →
   `np.asarray(...)[:, :, ::-1]` 转成 **BGR** 数组。最后这步反转是因为
   PIL 用 RGB 顺序、OpenCV/Ultralytics 用 BGR 顺序，不一致会导致
   颜色信息错乱、检测性能下降。`[:, :, ::-1]` 是 numpy 切片语法
   "把第三维倒序"；
3. **推理**：`MODEL.predict(source=bgr_array, imgsz=640, conf=conf, ...)`，
   参数与你做正式评估时的协议一致（imgsz 640）。外面包了
   `time.perf_counter()` 计时得到端到端耗时 `wall_ms`；
4. **画图**：`result.plot()` 一行完成"掩码半透明叠加 + 边界框 + 类别标签"
   的绘制，返回 BGR 数组；再反转回 RGB 交给 PIL 存进内存中的
   `BytesIO`（质量 88 的 JPEG），最后 `base64.b64encode()` 变文本；
5. **提数据**：遍历 `result.boxes`，把每个实例的类别号、置信度、
   xyxy 边界框（左上/右下坐标）整理成列表，按置信度降序。
   `result.speed` 是 ultralytics 自带的分阶段计时
   （预处理/网络前向/后处理），一并返回。

最后打包成一个大字典返回，FastAPI 自动把字典序列化成 JSON。

函数为什么是 `async def`？为了用 `await file.read()` 异步读上传流。
推理本身是同步阻塞的——对单人演示完全没问题；如果将来要做多人并发，
需要把推理丢进线程池（文档末尾的练习里提到）。

### 5.6 兜底异常处理与 `main()`

```python
@app.exception_handler(Exception)
async def unhandled_exception_handler(request, exc):
    return JSONResponse(status_code=500, content={"detail": f"服务内部错误：{exc}"})
```

没有它，未捕获的异常会让 FastAPI 返回一个 HTML 格式的 500 页面，
前端解析不了。注册后所有意外错误统一变成 JSON，前端能显示中文原因。

`main()` 是命令行入口：`argparse` 解析 `--weights/--device/--host/--port`
（所以 `python demo/app.py --port 8001` 能换端口），先 `init_model()`
再 `uvicorn.run(app, ...)` 启动 HTTP 服务器。uvicorn 就是真正监听端口、
收发数据的"服务器引擎"，FastAPI 负责"路由和解析"，两者是分工关系。
`log_level="warning"` 屏蔽每请求一条的访问日志，控制台清爽。

## 6. 前端 `index.html`：页面骨架

HTML 只负责"有什么"，不管长什么样（CSS 管）、不管行为（JS 管）。
页面分四大块，`id` 属性是 JS 找它们的钥匙：

| 区块 | 关键 id | 作用 |
|---|---|---|
| 页头 `header.topbar` | `meta-chips` | 软件名 + 徽标；右侧芯片由 JS 填充设备/权重/类别 |
| 左栏（输入） | `dropzone`、`file-input`、`samples`、`conf`、`detect-btn`、`status` | 三步操作流：选图 → 参数 → 按钮 |
| 右栏（输出） | `viewer-img`、`stats`、`inst-tbody`、`history` | 结果图、统计卡片、明细表、历史 |
| 全局 | `toast` | 底部短暂弹出的提示条 |

几个值得注意的细节：

- `<input type="file" ... hidden>`：真正的文件选择框被隐藏，点击虚线框
  （dropzone）时代理触发它。原生文件框太丑，这是标准做法；
- `<input type="range">`：原生滑块，一行代码获得拖动手柄，
  `min/max/step/value` 控制范围和步长；
- `hidden` 属性：HTML 原生的"隐藏开关"，JS 切换它来控制占位图/结果图、
  下载按钮的显隐；
- 页签图标那行 `data:image/svg+xml,...`：把一个 emoji 直接内嵌为图标，
  避免额外的 favicon 文件请求；
- `<script src="/static/app.js">` 放在 `</body>` 前：保证脚本执行时
  页面元素都已存在，JS 拿得到它们。

## 7. 前端 `style.css`：页面的皮肤

CSS 不需要逐行读，掌握这几个"套路"就能看懂大意、敢于修改：

**① CSS 变量（文件开头 `:root { --green: #2f7d32; ... }`）**
把所有颜色、圆角集中定义，后文写 `color: var(--green)`。
想换主题色？只改 `:root` 里一行，全页跟着变。你后端 `CLASS_META`
的类别色和这里 `--amber`/`--cyan` 是同一套色值——颜色统一是"软件感"的来源。

**② 布局两板斧**
- `display: flex`：一维排列。页头里 logo 和标题横排、统计卡片自适应换行
  都是它；
- `display: grid`：二维网格。主布局 `grid-template-columns: 380px 1fr`
  表示"左栏固定 380 像素，右栏吃掉剩余宽度"。文件末尾的
  `@media (max-width: 960px)` 是响应式：窗口太窄时改成单栏上下堆叠，
  手机上也能看。

**③ 状态与过渡**
`.dropzone:hover, .dropzone.dragover { border-color: ... }`——鼠标悬停或
拖文件经过时边框变色。JS 拖拽时给元素加上 `dragover` 类、离开时移除，
配合 CSS 就有了"呼吸感"。`transition: 0.15s` 让变化有 0.15 秒渐变动画。

**④ 小技巧两处**
- 结果查看区的棋盘格背景（`repeating-conic-gradient`）：让透明区域
  一眼可辨，修图软件同款；
- `font-variant-numeric: tabular-nums`：数字等宽，阈值滑动时数字不抖。

**怎么找"某个效果在哪**：浏览器里按 F12 打开开发者工具，点左上角的箭头
再点页面元素，右侧 Styles 面板就高亮出对应的 CSS 规则和所在文件行号。
这是改样式最有效率的工作方式。

## 8. 前端 `app.js`：页面的大脑（逐函数讲）

整个文件的组织：顶部一个 `state` 对象存数据，十来个函数各管一摊，
最底下 `init()` 启动。**没有框架、没有构建工具**，原生 JS 就够了。

### 8.1 状态与工具

```js
const state = { file: null, originalUrl: null, result: null, history: [] };
const el = (id) => document.getElementById(id);
```

- 集中一个 `state` 对象而不是散落各处的变量，页面任何时刻"正在处理
  哪张图、最近结果是什么"一目了然；
- `el("detect-btn")` 是 `document.getElementById("detect-btn")` 的缩写，
  这文件里要用几十次。

`toast(message)`：底部黑底白字提示条。`toast._timer` 这个写法利用了
"JS 函数也是对象"的特性，把定时器挂在函数自己身上——连续调用时先
清掉上一个定时器，提示不会提前消失。

`setStatus(message, isError)`：写左栏那行灰色状态字，出错时变红
（`classList.toggle` 增删 CSS 类）。

`readError(response)`：后端报错时返回的是 JSON（如
`{"detail": "图片超过 20MB..."}`），这个函数把 `detail` 提取出来给人看；
万一响应不是 JSON（比如网络层直接挂了），退回显示 HTTP 状态码。

### 8.2 启动：`init()` → `loadInfo()` + `loadSamples()` + `bindEvents()`

`async function init()` 按顺序 await 三个异步函数。为什么是异步？
网络请求需要时间，`await fetch(...)` 的意思是"等结果回来再往下走"，
期间页面不卡死。

`loadInfo()`：

```js
const response = await fetch("/api/info");
if (!response.ok) throw new Error(await readError(response));
const info = await response.json();
```

这四行是 JS 调 API 的标准姿势，后面处处复用：`fetch` 发请求 → 检查
`response.ok`（2xx 状态码）→ `.json()` 把响应体解析成 JS 对象。
之后把设备、权重、参数量（`23865205 / 1e6` → 显示 "23.9M"）、类别
拼成芯片 HTML 塞进 `meta-chips`。`innerHTML` 配模板字符串
（反引号 + `${变量}`）是 JS 拼 HTML 的常用写法。

`loadSamples()`：请求示例列表，为每一张生成一个 `<button>` 缩略图。
注意创建元素用的是 DOM API（`createElement` + `appendChild`）而不是
innerHTML——因为每个按钮还要挂独立的 click 事件。点击按钮的逻辑：
`fetch` 拿到图片 → `blob()` 读成二进制 → 包装成 `File` 对象 → 交给
`setFile()`，**和用户自己上传走完全相同的路**，一套逻辑两处复用。

### 8.3 选图：`setFile(file)` —— 三种入口汇成一条河

点击、拖拽、粘贴三种方式最终都调它，内部做四件事：

1. 类型与大小校验（正则 `/^image\/(jpeg|png|bmp|webp)$/` 匹配 MIME 类型）；
2. `URL.createObjectURL(file)` 生成本地预览地址。这个 URL 指向浏览器
   内存的副本，**不经后端**，所以预览是即时的；换图前
   `revokeObjectURL` 释放旧的，防止内存泄漏；
3. 显示原图预览、启用检测按钮、清空上一次的统计和表格——
   "新图未检测"的界面状态复位；
4. 状态栏显示文件名和大小。

### 8.4 检测：`detect()` —— 全文最核心的 30 行

```js
const formData = new FormData();
formData.append("file", state.file);
formData.append("conf", el("conf").value);

const response = await fetch("/api/predict", { method: "POST", body: formData });
```

- `FormData` 对应 HTTP 的 multipart/form-data 格式，两个字段的
  名字 `file`/`conf` 与后端 `predict(file: UploadFile, conf: float = Form(...))`
  的参数名严格一致——**前后端的契约就是这两个字符串**；
- fetch 不写 `method` 默认是 GET，上传必须显式写 `POST`；
- `body` 直接给 FormData，浏览器自动带上正确的编码头。

成功后 `state.result = data`，交给 `renderResult()` 和 `appendHistory()`。
注意 `try...finally`：无论成功失败，`finally` 块里恢复按钮状态，
保证出错后按钮不会永远卡在"检测中"。这个细节很多新手会漏。

### 8.5 渲染：`renderResult(data)`

拿到后端的 JSON 后分三步画界面：

1. **结果图**：`viewerImg.src = "data:image/jpeg;base64," + data.image`。
   `data:` 前缀 + base64 字符串 = 浏览器可以直接显示的"内嵌图片 URL"，
   和后端的编码方式严丝合缝；
2. **统计卡片**：先遍历实例列表按类别计数（`perClass` 对象累加），
   再拼出"总数 / 各类别数 / 前向耗时 / 端到端耗时"几张卡片。
   类别色通过 `style="--accent:${color}"` 注入 CSS 变量，卡片左侧的
   色条颜色就跟着类别走；
3. **明细表**：`data.instances.map(...).join("")` 把每个实例转成一行
   `<tr>` HTML。空结果时给出一行"可尝试调低置信度"的引导文案，
   而不是干巴巴的空表格。

### 8.6 历史与回看：`appendHistory(data)`

每次检测 `unshift` 进数组头部、超过 8 条 `pop` 掉末尾。
点击历史缩略图回看：把当时的 result 重新交给 `renderResult`，
并**同步把阈值滑块恢复到当时的值**——细节决定"软件感"。
只存内存，刷新即清空，演示场景够用（想持久化可存 localStorage，见练习）。

### 8.7 事件绑定：`bindEvents()` —— 七类事件一览

| 事件 | 元素 | 处理 |
|---|---|---|
| click | dropzone | 触发隐藏的 file-input |
| change | file-input | 取 `files[0]` 交给 setFile，随后 `value = ""` 清空——否则连续选同一张图不触发 change |
| dragover / dragleave / drop | dropzone | 拖入高亮、离开还原、放手取第一个文件。`event.preventDefault()` 必须调，否则浏览器直接打开图片文件 |
| paste | document | 从剪贴板 items 里找 image 类型，截图后直接 Ctrl+V |
| input | conf 滑块 | 实时回显数值 |
| click | detect-btn | 调 detect() |
| change | show-orig 勾选框 | 在原图 objectURL 和结果 base64 之间切换 src |

外加下载按钮：临时造一个 `<a>`，把 base64 设为 `href`、文件名设为
`download`，`click()` 触发浏览器下载——不需要后端参与。

## 9. 常见问题排查（对照现象找原因）

| 现象 | 原因与解法 |
|---|---|
| 打不开页面 | 服务没起来看控制台报错；端口被占用加 `--port 8001`；确认地址栏是 `127.0.0.1:8000` 而非 `localhost`（个别代理软件会劫持后者） |
| 报"权重文件不存在" | `runs/` 未回传该 Run；或用 `--weights` 指定别的 best.pt |
| 页面开了但示例图转圈 | 后端起了但 `/api/samples` 报错，F12 → Network 看该请求的响应内容 |
| 上传后弹"不支持的图片格式" | 文件后缀不在白名单；注意 HEIC（iPhone 默认格式）不在内，先转 JPG |
| 检出 0 个实例 | 正常现象——图里没虫或目标太小。把阈值滑到 0.10 再试；换成真实分辨率图片效果更好 |
| 掩码看不清 | 害虫目标小 + 示例图降采样，掩码只有两千多个像素。用真实数据集图片替换 `samples/` 后会明显改善 |
| 控制台中文乱码 | PowerShell 先执行 `$env:PYTHONUTF8='1'` 再启动 |
| 想让别人（同 WiFi）访问 | 启动加 `--host 0.0.0.0`，对方访问 `http://你的IP:8000`；Windows 防火墙放行 8000 端口 |

## 10. 动手改一改（按难度排序的练习）

改代码是理解代码最快的方式，每题都给出关键提示：

1. **改软件名/副标题**：`index.html` 的 `<h1>` 和 `<p>`，以及
   `app.py` 顶部 `SOFTWARE_NAME`。两处都要改，页头标签和网页标题才一致；
2. **换主题色**：`style.css` 的 `:root` 里 `--green` 换成你喜欢的颜色
   （搜"hex 颜色码"）；
3. **改默认阈值和范围**：`index.html` 滑块的 `value`/`min`/`max`，
   `app.py` 的 `Form(0.25)` 默认值也同步改；
4. **加 IoU 阈度滑块**（学前后端联动）：前端照抄 conf 滑块三件套 →
   `detect()` 里 `formData.append("iou", ...)` → 后端
   `predict` 加参数 `iou: float = Form(0.7)` → `MODEL.predict(..., iou=iou)`；
5. **历史记录存本地**：把 `state.history` 序列化进
   `localStorage.setItem("dss_history", JSON.stringify(...))`，
   页面加载时读回——注意 base64 图片很大，只存缩略信息更合适；
6. **并发安全**：把推理挪进线程池（`await asyncio.to_thread(MODEL.predict, ...)`），
   让多人同时检测时也不互相阻塞。
