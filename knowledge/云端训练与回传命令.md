## 2. 正式训练（已启动则只需附回查看）

首次启动（四行在同一 tmux 会话内一次性粘贴）：

```bash
tmux new -s cmp2-nosfcm
cd "${HOME}/yolo_plus"
set -o pipefail
log_file="${HOME}/yolo_plus/data-v2-cmp2-nosfcm-b16-s42.log"
PYTHONUNBUFFERED=1 python scripts/cloud_train_data_v2.py \
  --config experiments/data-v2-cmp2-nosfcm-b16-s42.yaml \
  --pretrained yolo26m-seg.pt 2>&1 | tee "${log_file}"
```

PuTTY 断线重连后：`tmux attach -t cmp2-nosfcm`，或 `tail -f ~/yolo_plus/data-v2-cmp2-nosfcm-b16-s42.log`。

## 3. 云端：完成后检查与打包

```bash
cd "${HOME}/yolo_plus"

# 自动发现带时间戳的真实 Run 目录（取最新的 nosfcm 目录）
run_id=$(ls -t runs | grep "data-v2-cmp2-nodual-b16-s42" | head -1)
echo "RUN_ID=${run_id}"

# 产物四项核对
test -f "runs/${run_id}/weights/best.pt"  && echo "best.pt OK"
test -f "runs/${run_id}/weights/last.pt"  && echo "last.pt OK"
test -f "runs/${run_id}/results.csv"      && echo "results.csv OK"
test -f "runs/${run_id}/args.yaml"        && echo "args.yaml OK"
tail -3 "runs/${run_id}/results.csv"      # 最终几行指标应有限

# 打包（zip 名自动继承时间戳：exports/${run_id}.zip）
python scripts/transfer_run.py pack --run-id "${run_id}"
ls -lh "exports/${run_id}.zip"
```

## 6. 回传后：登记与判读

1. 在 [消融实验设计与登记表.md](消融实验设计与登记表.md) 第 3 节 `nosfcm` 行填入：
   best epoch（official fitness = Box mAP50-95 + Mask mAP50-95 最大的行）、fitness、
   Mask mAP50 / mAP50-95、Δ vs cmp1（= 消融值 − 0.38929）、Δ vs 000（= 消融值 − 0.36348）、判定。
2. 判读口径（预注册，不随结果调整）：
   - **|Δ vs cmp1| ≥ 0.005** → 前景门有真实贡献，贡献量 = 0.38929 − 消融值，SFCM 保留；
   - **|Δ vs cmp1| < 0.005** → 门无独立贡献（噪声内），按死组件剔除规则：最终模型移除门
     （保留语义辅助监督），论文 SFCM 节改写为"辅助语义监督消融"；
   - **消融值 > cmp1** → 门为负贡献，同样剔除，论文作负结果讨论。
3. 分类型与成本两行（登记表第 5、6 节）从训练日志尾部分类型行与 fused summary 行抄录。

