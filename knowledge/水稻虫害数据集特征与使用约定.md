# 水稻虫害数据集特征与使用约定

更新日期：2026-09-14。适用数据版本：`rice-pest-data-v2`。

本文保存后续结构设计、结果分析和论文写作共用的数据背景。采集信息来自用户说明；数量和几何特征来自现有数据配置、实验总表及 train/val 几何统计。

## 1. 快速认识数据集

本课题使用无人机在约 **3 米高度**航拍稻田，识别两类水稻虫害：卷叶螟（Rice leaffolder）和钻心虫（Rice stemborers）。当前技术任务是 **实例分割**，每个标注实例具有类别和多边形轮廓，模型需要同时识别、定位和分割目标区域。

用户对数据的概括是“小目标为主”。已有标注统计进一步表明：**细长、窄边、小面积掩膜是核心特征，尤其是卷叶螟类别。** 图像中有密集稻叶、稻穗等背景纹理，目标与背景共享细长形状。结构设计应同时考虑窄边细节、长方向信息及背景区分能力。

## 4. 目标形态与尺寸

### 4.1 统计口径

本节合并 **Train+Val：1055 张图像、4626 个多边形标注**，其中卷叶螟 3607 个、钻心虫 1019 个。

将每张图像按最长边等比缩放至 640，缩放系数为 `640 / max(图像宽, 图像高)`，再计算标注几何量。长度单位为缩放后的像素，面积单位为像素平方；统计发生在平移填充之前，不含随机训练增强。

- **水平框**：与图像坐标轴平行的多边形外接框。
- **旋转框**：用 OpenCV `minAreaRect` 计算的最小面积外接矩形；短边和长边用于描述目标宽窄及延伸程度。
- **多边形面积**：连续轮廓面积，使用 `contourArea` 计算。
- **长宽比**：逐个实例的旋转框长边除以短边，再统计分布。

### 4.2 两类别几何对比

| 指标（Train+Val，最长边 640） | 卷叶螟 | 钻心虫 |
|---|---:|---:|
| 旋转框短边中位数 / px | 7.191 | 22.386 |
| 旋转框长边中位数 / px | 81.737 | 92.471 |
| 旋转框长宽比中位数 | 10.922 | 3.865 |
| 连续多边形面积中位数 / px² | 391.776 | 1098.971 |
| 多边形面积 / 水平框面积的中位数 | 0.261 | 0.359 |
| 旋转框短边 <8 px 的实例占比 | 64.82% | 2.65% |
| 多边形面积 <1024 px² 的实例占比 | 96.09% | 46.22% |
| 水平框面积 <1024 px² 的实例占比 | 35.29% | 11.19% |

两类标注的长边中位数相近，短边差异明显。卷叶螟通常更窄、更细长，分割时需要处理更薄的目标区域。各项中位数独立计算，长边中位数除以短边中位数不等于长宽比中位数。

### 4.3 “小目标”需要注明测量方式

Train+Val 全部实例中：

| 判定方式 | 实例数 | 占比 |
|---|---:|---:|
| 连续多边形面积 <1024 px² | 3937 / 4626 | 85.11% |
| 水平框面积 <1024 px² | 1387 / 4626 | 29.98% |

细长目标倾斜时，水平外接框可能包含大量背景，使框面积明显大于实际标注区域面积。描述数据时应同时交代小面积和窄边特征。

已有小卷叶螟专项评估采用 **Val 卷叶螟水平 bbox@640 面积 <1024 px²**，共有 **174 / 462 个实例（37.66%）**。同一 Val 中旋转框短边 <8 px 的卷叶螟有 **285 / 462 个（61.69%）**。两个集合按不同条件定义，后续复用专项评估时沿用 174 个实例的既有口径。

仅 Val 的卷叶螟短边中位数为 **7.325 px**；Train+Val 合并值为 **7.191 px**。引用时保留对应的 split 范围。

## 5. 对模型结构设计的含义

以下是由数据几何和图像观察提出的设计动机，具体收益由消融实验判断。

| 数据特征 | 需要关注的模型能力 |
|---|---|
| 卷叶螟短边中位数约 7.19 px | 下采样后的窄边表征、浅层细节传递和掩膜边界表达 |
| 卷叶螟长宽比中位数约 10.92 | 沿目标延伸方向聚合信息，同时保留局部形状 |
| 稻叶、稻穗与目标共享细长纹理 | 前景与背景区分，关注增加召回时是否同时增加误检 |
| 类别数量和几何形态不同 | 同时分析两类别 AP，观察总体收益由哪类贡献 |
| 部分图像具有多个目标，另有纯背景图像 | 多实例区分能力、重复预测及背景图误检 |

以 stride=8 的 P3 为例，7.191 px 短边约对应 0.90 个网格间距。这提供了研究细节保留的动机。掩膜面积小、细长及背景混淆也意味着，只观察 Box AP 或固定阈值召回率不足以评价实例分割改进。

## 6. 当前实验使用约定

数据版本和划分固定。Train 用于学习参数，Val 用于方案选择，Test 在最终方案与阈值冻结后统一评估。

当前 Baseline 为 `YOLO26m-seg`，正式配方使用 `imgsz=640`、`epochs=300`、`batch=16`、`seed=42`、`AdamW`、`mask_ratio=2`。完整参数以 [实验总表表 1](../云服务器实验设计与记录表.md) 为准。

`best.pt` 按官方分割 fitness（Val Box mAP50-95 + Val Mask mAP50-95）选择，结构改进的主比较指标为 **Val Mask mAP50-95**，同时报告 Mask mAP50。原图 COCO 专项评估使用独立协议，其数值与正式训练验证结果分别记录。

实验进度从 [PROGRESS](../PROGRESS.md) 查阅；各方案结果从 [正式 Run 记录目录](../experiment_records/runs/) 查阅。

## 7. 已知限制与待补充采集信息

- 约 3 米航拍高度来自用户说明；相机型号、焦距、地面采样距离、采集地点和日期尚未在本文来源中确认，无法由高度直接换算目标实际尺寸。
- 几何统计描述标注区域。虫体、受害叶片或症状区域的具体标注语义，应以采集与标注规范为准；论文中的生物学描述仍需该规范支持。
- 现有文件名包含 `2x2`、`3x3` 和行列位置等信息；原图裁切规则及划分是否按原始航拍图或地块分组，需依据数据制作记录说明。
- 表中实例数和几何统计按原始标签行计算。既有训练日志显示，`Rice_leaffolder_3x3_p0020_r0c2.jpg` 与 `Rice_leaffolder_3x3_p0032_r1c1.jpg` 各有 1 个重复标签被加载器移除；Train/Val 日志均为 0 corrupt。比较实验保持相同加载口径。
- 连续多边形面积、栅格掩膜面积和水平框面积是不同量；本文的 640 尺寸分组不直接等同于标准 COCO 原图面积分组。网格间距换算也不代表目标在特征图中必然消失。
- 本文沿用已登记的 Test 数量，几何分析仅涉及 Train/Val。现有正式结构实验使用单个 seed=42。
