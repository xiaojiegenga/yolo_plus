# 改进 E：DySample 动态上采样原理与实现

**一句话：把 Neck 中两处“固定复制特征”的上采样，换成“根据特征内容学习去哪里取值”的上采样。**

E 是独立结构实验，训练结果待验证。

## 1. 先认识三个基础概念

| 概念 | 可以怎样理解 | 在本项目中的作用 |
|---|---|---|
| 特征图 | 网络从图片中提取出的多层数值地图 | 表示纹理、形状和类别等信息；不是缩小后的彩色照片 |
| Neck | 连接骨干网络与预测头的特征融合部分 | 把不同尺度的信息放到一起使用 |
| 上采样 | 增加特征图的宽和高 | 让两个不同大小的特征图能够拼接 |

输入图片为 640×640 时，P3、P4、P5 特征图的空间尺寸分别为 80×80、40×40、20×20。
P3 的网格更细；P5 来自更深的层，提供不同层次的语义信息。Neck 把它们逐步融合。

## 2. 原来怎样上采样？

Baseline 使用最近邻上采样。以 2×2 放大到 4×4 为例：

```text
原来的特征值             最近邻放大后
1  2                    1  1  2  2
3  4                    1  1  2  2
                        3  3  4  4
                        3  3  4  4
```

优点是简单、开销低。但取值规则固定，不会根据虫体边缘或局部纹理调整采样位置。
对小目标而言，特征图中的少量位置变化可能影响后续定位与分割，因此值得验证更灵活的取值方式。

## 3. DySample 做了什么？

它保留上采样这件事，增加一个很小的网络来预测**采样位置的偏移量**。

```text
输入特征图 ──→ 1×1 卷积 ──→ 预测横向、纵向偏移
     │                              │
     └────────→ 按调整后的位置取值 ←──┘
                         │
                         ↓
                  放大后的特征图
```

可以把它理解为：原来在固定位置取值，现在允许网络把取值位置向左、右、上、下稍作移动。
位置可能落在两个像素之间，此时用**双线性插值**，按距离混合附近四个位置的值。
这些偏移由输入特征预测，随训练一起学习，因此叫“动态”上采样。

上采样不会凭空恢复已经丢失的信息；本次假设是，更合适的取值位置能够改善后续特征融合。

## 4. 本次具体改了哪里？

只替换模型第 **11、14 层**，层号从 0 开始。

| 位置 | 空间尺寸变化（640 输入） | 原模块 | E 模块 |
|---|---|---|---|
| 第 11 层：P5→P4 | 20×20→40×40 | 最近邻上采样 | DySample，放大 2 倍 |
| 第 14 层：融合后的 P4→P3 | 40×40→80×80 | 最近邻上采样 | DySample，放大 2 倍 |

```text
P5 20×20 → DySample → 40×40 → 与骨干 P4 拼接、融合
                                      ↓
                                  DySample
                                      ↓
                         80×80 → 与骨干 P3 拼接、融合
                                      ↓
                              原有检测与分割头
```

模型 YAML 中两处改动均为：

```yaml
# Baseline
- [-1, 1, nn.Upsample, [None, 2, "nearest"]]

# E：2 表示放大倍数，4 表示采样分组数
- [-1, 1, DySample, [2, 4]]
```

采用作者的 **LP 形式**：先在低分辨率特征上预测偏移，再重新排列采样坐标。
通道分为 4 组，每组共享一套采样位置；偏移乘以固定系数 0.25。
偏移卷积以标准差 0.001 的小随机权重初始化，偏置为 0，初始行为接近双线性上采样。
它不等于原来的最近邻上采样。

## 5. E 与 D1 有什么区别？

| 项目 | D1 | E |
|---|---|---|
| 修改位置 | 掩码原型分支 | Neck 的两处上采样 |
| 主要假设 | 更细的原型网格改善掩码表达 | 内容自适应取值改善多尺度特征融合 |
| 640 输入时原型尺寸 | 320×320 | 160×160，与 Baseline 相同 |
| 检测尺度 | P3/P4/P5 | P3/P4/P5 |
| 当前状态 | 正式主指标 0.37327，有正向结果 | 实现完成，正式训练待运行 |

本次先训练 **Baseline+E**。后续根据结果决定是否训练 **Baseline+D1+E**，
用 Baseline、D1、E、D1+E 四组结果分别说明模块贡献与组合收益。

## 6. 源码文件在哪里？

源码分支：`feature/data-v2-abl-e-dysample`，从正式 Baseline `c0f4f35` 创建。

| 文件 | 作用 |
|---|---|
| `ultralytics-main/ultralytics/nn/modules/dysample.py` | DySample 本体：预测偏移、生成坐标、采样 |
| `ultralytics-main/ultralytics/nn/modules/__init__.py` | 导出模块，让框架能够导入它 |
| `ultralytics-main/ultralytics/nn/tasks.py` | 解析 YAML，并把输入通道数传给模块 |
| `ultralytics-main/ultralytics/cfg/models/26/yolo26m-dysample-seg.yaml` | 定义两处替换位置 |
| `experiments/data-v2-abl-e-dysample-b16-s42.yaml` | 正式训练配置，沿用 Baseline 配方 |
| `scripts/check_dysample.py` | 合成输入检查与官方权重迁移检查 |

模型共增加 **32,832 个参数**，融合后为 **23,541,842**，较 Baseline 约增加 **0.14%**。
原有权重键和形状保留；预训练权重仍是官方 `yolo26m-seg.pt`。
训练入口在构建模型前设置 seed=42，使新增偏移卷积的初始化可重复。

## 7. 已检查的内容与限制

7 项 CPU 检查通过，包括坐标方向、矩形输入、模型结构、正样本与空样本损失反向、权重保存融合、配方和初始化。
与作者 LP 实现的 FP32 输出及梯度一致；本机 RTX 4060 Ti 的 AMP 分割损失反向和 FP16 推理通过。
云端仍需运行一次检查，确认 RTX 5090 环境。

- CUDA 的 `grid_sample` 反向在当前本机 PyTorch 中不是确定性实现。`deterministic=true` 保持冻结值，
  框架采用警告模式，不阻止训练；同 seed 不保证最终结果逐位相同。
- THOP 显示约 121.228 GFLOPs，但不统计 `grid_sample` 等函数算子，不能把这个数当作完整成本。
  实际耗时和显存以云端记录为准。
- E 尚无训练结果，不能预先认定有效。DySample 是已有方法，本项目贡献是结构接入与任务验证，论文应引用原作者。
